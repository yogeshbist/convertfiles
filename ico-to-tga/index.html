Why convert ICO to TGA?

People convert ICO to TGA because ICO is a Windows icon container that ordinary image software treats as a curiosity rather than a picture, while TGA is what a number of game engines and older 3D tools still expect.

What is a .ico file?

ICO is the Windows icon container, used for favicons and application icons. One file can hold the same image at several sizes so the system can pick the right one; 16, 32, 48 and 256 pixels are the usual set.

What is a .tga file?

TGA is a simple, usually uncompressed image format that persists in game development and 3D texturing pipelines, where its straightforward alpha channel is convenient. General-purpose software often cannot open one.
