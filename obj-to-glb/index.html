About Wavefront OBJ

OBJ is a plain-text 3D mesh format from the 1990s that almost every 3D program can read and write. It carries geometry and, through a companion .mtl file, materials.

About glTF (binary)

GLB is the binary form of glTF, the 3D format used by web viewers, Android’s AR Scene Viewer and modern game engines. One file holds the whole scene.

What to expect

Geometry is converted exactly, with node transforms applied. Materials, textures and animations are not carried; check the scale in your viewer, since STL files are unitless.
